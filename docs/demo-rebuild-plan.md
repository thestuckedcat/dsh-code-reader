# Demo 同源右栏重构实施计划

2026-11-19，依据用户“完全复刻当前 demo，从头大改”。实现授权沿用本轮指示。

**目标：** 原生右栏直接使用当前 Demo 的五视图、画布和交互；真实快照经适配器进入同一渲染器。

**架构：** `demo/code-view/index.html` 是视觉与交互基线。构建器将其内联进客户端，不维护第二套样式。原生右栏壳只负责生命周期、来源选择与已准入的 RPC。快照适配器保留确定性和缺口，不把静态推断写成运行观测。

**来源与边界：** Demo 取本仓当前字节，直接复用；02 `client.js` 原生 `sidebarRightTabs` / `sidebar.right.pane.tab` 接缝只借鉴机制；宿主固定本机 0.2.1-rc.5；04 当前 Host RPC、快照核验直接复用。浏览器样例仅执行内置 Wasm；真实源代码不直接执行。只启动隔离验收宿主，不重启用户桌面。

## 文件与步骤

1. `client/entry.cjs` 原生右栏壳：注册页面类型和 body/title，左侧入口仅打开右栏；释放注册与异步请求。验证无 main/根 rightbar 替换、重挂载、缺依赖显示。
2. `client/document.cjs` 与 `tools/build-workbench.mjs`：同源内联文档及可校验构建。默认文档保持 Demo 字节；模型模式复用画布/源码/资源/文字树的渲染函数。验证构建可复现、来源哈希、包包含完整运行资源。
3. `client/model.cjs`：RPC DTO → Demo 读模型。稳定 ID 映射、同名函数/资源隔离、跨仓文件、资源证据、标准形状、竖向布局。真实快照不灌入样例业务字段，不伪造运行轨迹/锁分析。
4. `tools/demo-rebuild-probe.cjs`：同视口画面对照与实际操作，覆盖五视图、拖动/复位、组/黑盒、源码/子流程、资源跳转、模拟回退、时序顺序、窄栏；隔离 rc.5 检查确实在右栏。

先增加失败回归，再实现各边界；修改后运行引擎/Host 回归与新真实浏览器探针。旧 UI 专属断言改为当前右栏合同，已存在的 RPC/引擎合同保持。

## 首个可验交付

从宿主入口打开右栏，当前 Demo 五视图全部可操作；关闭后聊天仍在主区域。比较相同视口的 Demo 与右栏内文档截图；再切到真实快照查看同一函数、资源定义和来源缺口。

## 复核重点

- 右栏尚无会话、依赖延迟就绪与卸载重开。
- 同名函数/资源与不同仓库同路径文件。
- 快照空、失效、RPC 失败、过量数据、部分控制流。
- 窄栏中画布可以平移阅读，不把所有节点缩成不可读大小。
- 静态关系、样例观测、真实运行观测明确区分。
