# 生成 04 插件的 DSH 侧边栏

此 skill 仅用于指导开发与复核 UI。实际产品是代码工作台插件，Host 提供证据、权限和执行能力；本文件不代替客户端和服务端实现。已落实的接入与验证见 [CL-UI-R1](../ui-demo-alignment.md)。

## 接入前核对

2026-11-19 修订以 [CL-UI-R1](../ui-demo-alignment.md) 为当前基准。默认在对话右侧打开工作台，先核宿主 `sidebarRightTabs`、`sidebarRight` 与页面扩展合同。root `rightbar` 已有宿主占用，通过原生扩展机制接入。历史 keyed main 方案迁移至右栏。

1. 查目标 Host 的版本、build、loader、runtime、右栏页面注册、唤起方式和 disposer。以隔离 profile 证据为准。08 的主面板接入记录仅用于 loader 与生命周期对照，右栏服务需单独核验。[08 宿主兼容矩阵](../../../08-workbench-ui/docs/compatibility-matrix.md)
2. 读取当前工作台 DTO、选择模型和范围限制。入口打开或恢复同一右侧工作台，保留当前对话及其他右侧页面。入口名称、排序和主题遵循宿主规则。[软件设计 §§3、4、9](../interactive-code-view-software-design.md)
3. 生成候选 UI 前画出入口打开、范围切换、资源定位、待加载、失败、停用的实际状态。对缺失能力直接显示具体原因与可用入口。

## 原生入口

- 使用宿主原生标签、尺寸、交互和焦点规则。入口名用「代码工作台」，位于原生右栏开始页；页面类型、body、title 使用各自 disposer。画布沿用用户选定的 Demo 调色板，避免生成另一套 UI。宿主外框仍采用原生主题。
- 点击侧边栏入口时恢复用户当前 workspace、入口、视图和选中位置，或显式列出需要选择的已登记 workspace。未加载快照时先显示已有可读能力。面板关闭、停用与卸载撤销插件自己的注册、响应和资源；回到宿主可导航位置。
- 兼容 rc.5 使用 `sidebarRightTabs` 与 `sidebar.right.pane.tab`/title。未知接缝标为 `needs_verification`，保留对话工具可用性，不用主区域页面替代右栏。业务 RPC 走 04 已授权 Host 适配；沙箱通过受限消息桥调用，所有执行仍由 Host 复核。

## Demo 同源与状态

- 修改 UI 时以 `demo/code-view/index.html` 和模板为视觉基线；运行 `node tools/build-workbench.mjs` 生成发布 bundle，`--check` 检查漂移。不要手改生成产物或另写一套图表皮肤。
- 静态快照经稳定 ID、仓库/路径复合键适配进同一渲染器。基础接口、组、异常色、字段与源码证据保留准确来源；缺失的 CFG/锁分析显示未知。
- 关闭重开保留视图、调用上下文、相机、布局、组/黑盒、详情和最后已完成场景。异步执行/回退/导入成功后主动保存状态；不能只靠点击事件或卸载期间的消息。
- 台账按当前快照与运行配置隔离。只有 observed DTO 的 `async=true` 可产生异步标记；不能从当前 profile 反推旧导入轨迹。

## 面板左栏

- 左栏提供「打桩模拟／全局资源」两个有名的入口。保持两栏原有滚动、选择和可编辑场景参数。窄屏可切换抽屉，返回后聚焦之前的行。由 Host 返回的数据驱动控件，样例路由名称只用于 fixture 与验证。
- 打桩模拟用「选接口 → 录入参数 → 调用 → 记录」组织。每条记录显示出参、状态来源、边界打桩与对后续的影响。回退按钮显示末尾可回退条数和不可用原因。执行必须由用户触发并通过 Host 能力校验。
- 全局资源行显示名称、类型、简短用途及字段来源。将当前函数直接相关的资源置顶和高亮，其他同级按稳定顺序。展开后显示原始 C 定义、初始化值、字段解释和引用。初始化、修改、释放、Read 用浅色条和文本。关联函数点击只在右侧定位与高亮，源码详情保持收起。支持键盘操作并提供可见焦点。
- 用同一个 `Selection` 发定位，包含工作区、快照、入口、符号及调用点。存在同名或多个上下文时使用明示选项。新选择覆盖旧响应时显示新范围，过期标签可回看版本。左栏按可见列表更新，选择变化仅重渲染相关行。

## 交接与验收

2026-11-21 [CL-RES-01](../interactive-code-view-software-design.md#11-资源变更链与共享状态关注cl-res-01) 尚待实现。资源关注视图以多选资源及字段变化为前景，调用过程用灰淡色与适量透明度；保留域/机制文字和可读焦点。锁保护属于具体调用上下文；未知保护与 Demo 模拟标志不升级为真实互斥。资源定义唯一、访问实例按上下文区分，黑盒摘要不能隐藏关注资源副作用。旧 49 项验收不证明新增视图通过。

使用相同 Demo C 源码与输入，在独立 Demo 和宿主右侧工作台执行 U01–U09。实际检查节点可见性、控制顺序、分组、资源定义、联动和模拟，保存同视口、同主题对照截图。关闭、恢复后核位置与选择。

输出本次宿主版本和实际接缝、涉及组件/DTO、视觉校验与操作证据。隔离 profile 运行：打开 → 切 workspace → 切左栏 → 资源展开 → 定位共享函数 → 返回并保留状态 → 卸载 → 再挂载。另查窄屏、两种主题、键盘、上下文取消和重复注册。截图或事件记录须来自 DSH 验证环境，浏览器 Demo 的结果可用于对照。执行、源码读取、模型出口由插件负责校验。[侧边栏验收 A02、A06、A10](../interactive-code-view-software-design.md#10-实施顺序验收合同和修订)
