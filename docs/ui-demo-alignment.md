## CL-UI-01 右侧承载

用户在 DSH 对话旁打开右侧工作台，支持关闭、恢复、拖动宽度和宿主已有的放大方式。关闭后保留对话与阅读位置。内部保留「打桩模拟／全局资源」工具栏和五视图，窄栏可收起工具区。左导航可以保留为可选唤起入口，默认承载位置为右侧。

本机 ASAR 内 `@deepseek-ai/dsh-client-ui-layout` 为 `0.2.1-rc.5`，client SHA256 为 `eb011a7b5699fac7f3ad0aa15408f46a6cf47f79b8cc15db1f81739e81e70587`。root `rightbar` 是单席位，已有 `dsh-client-ui-sidebar-right` 占用并提供 `sidebarRightTabs` 和 `sidebarRight` 服务。接入前核对类型注册、页面内容与入口扩展合同，通过宿主右栏的扩展机制装入工作台。直接抢占根席位会与现有右侧页面冲突。历史 keyed main 方案需迁移，当前修订优先。

首个可验交付为对话旁打开右侧工作台，查看可读的资源图和发送主线，关闭、恢复后保留位置。源码范围、快照核验、隔离执行与权限由插件 Host 校验。完成证据需包含实际界面操作与对照截图。
